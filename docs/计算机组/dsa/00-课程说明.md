# 课程说明

这门课不只讲“数据结构”。课件的主线是：先把现实问题写成数学模型，再选择合适的数据组织方式和求解算法，最后讨论数值误差、算法设计方法、优化技术与计算复杂性。

| 模块 | 主要内容 |
|---|---|
| 算法基础 | 数据、数学模型、算法性质、时间与空间复杂度 |
| 数据结构 | 线性表、栈、队列、串、树、图、并查集 |
| 非数值算法 | 查找、索引、散列、排序 |
| 数值算法 | 误差分析、线性与非线性方程、拟合与插值、最优化 |
| 算法设计 | 蛮力、分治、减治、变治、贪心、动态规划、搜索、随机算法 |
| 进阶内容 | 输入增强、预构造、时空权衡、算法组合、P/NP 问题 |
