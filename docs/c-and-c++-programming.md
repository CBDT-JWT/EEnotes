# 计算机程序设计基础

## C 部分（计算机程序设计基础（1））

## 1. 绪论

C 语言由 Bell 实验室的 D. M. Ritchie 在 1972 年研制，最初和 UNIX 系统一起发展起来。

### 1.1 程序、算法与结构化设计

**算法**：解决一类问题的一组有限步骤。每一步都得写清楚，而且最终必须停下来。只说“不断尝试，直到成功”不算完整的算法，因为没有说明怎样尝试，也不能保证一定结束。

从题目到程序，大致要走下面几步：

1. 分析问题，明确输入、输出和约束；
2. 建立数学模型，选择数据结构和算法；
3. 用流程图、NS 图或伪代码描述流程；
4. 编码、编译、链接、运行；
5. 测试并调试。

结构化程序归根到底只有三种结构：**顺序、选择、循环**。复杂程序看着长，其实也只是这三种结构的嵌套，再加上函数拆分。

传统流程图用箭头表示控制流，容易出现随意跳转，也不便于表示嵌套。NS 图把每个基本结构画成一个方框，结构边界、作用域和嵌套关系更清楚。

### 1.2 测试与调试

测试是为了找错，不是为了证明程序没错。自己测程序时，至少准备这几类数据：

- 正常情况；
- 边界值，如 0、1、最大值、最小值；
- 特殊情况，如空输入、重复值、除数为 0；
- 非法输入（题目要求处理时）。

错误大致分四类：

- **编译错误**：语法、类型或声明有问题；
- **链接错误**：函数只有声明却没有定义，或缺少所需库；
- **运行错误**：越界、空指针解引用、除零等；
- **逻辑错误**：程序能运行，但算法或边界处理不对。

调试时先看中间量从哪一步开始不对。找到第一个错误状态后再往前追，比看到答案不对就到处改代码靠谱得多。

### 1.3 程序设计语言与 C 程序

机器语言直接写机器指令，汇编语言用助记符代替二进制指令，高级语言则更接近人的表达。C 程序从源文件到真正运行，中间还要经过**预处理、编译、链接**。

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d\n", a + b);
    return 0;
}
```

- `#include <stdio.h>` 引入标准输入输出函数的声明；
- `main` 是程序入口，返回类型写成 `int`；
- 花括号围成函数体或复合语句；
- C 区分大小写，一般语句以分号结束；
- 注释可写成 `/* ... */` 或 `// ...`。

## 2. C 语言的基本数据类型

### 2.1 进位计数制

一个 $r$ 进制数中，第 $k$ 位的位权是 $r^k$。二进制转八进制时每 3 位一组，转十六进制时每 4 位一组，这比先转十进制省事。

- 十进制整数转 $r$ 进制：除 $r$ 取余，余数逆序排列；
- 十进制小数转 $r$ 进制：乘 $r$ 取整，整数部分顺序排列；
- $r$ 进制转十进制：各位数字乘相应位权后求和。

有些十进制小数换成二进制会变成无限小数，所以浮点计算会带一点舍入误差。判断两个浮点数“相等”时，一般看误差是否足够小，不要想当然地直接用 `==`。

### 2.2 整数在计算机中的表示

这几个概念容易混，按转换顺序记：**原码 $\rightarrow$ 反码 $\rightarrow$ 补码**。负数原码的最高位是 1；求反码时符号位不动，其余位取反；反码再加 1 就是补码。正数的三种表示相同。

机器里实际用补码存有符号整数。这样加减法可以共用一套运算规则，0 也只有一种表示。

**偏移码**可以由补码把符号位取反得到，正数最高位为 1，负数最高位为 0。浮点数的阶码就是用偏移码保存的。

**定点数**的小数点位置固定；**浮点数**则把数写成类似科学计数法的形式。课件按 IEEE 754 讲 `float` 和 `double`：一段存符号，一段存带偏移的阶码，剩下的存尾数。因此浮点数能表示很大的范围，但有效数字有限。

对 $n$ 位整数：

- 无符号数范围为 $0\sim 2^n-1$；
- 二进制补码有符号数范围为 $-2^{n-1}\sim 2^{n-1}-1$。

`int` 不一定永远是 32 位，具体大小看平台，可以用 `sizeof` 或 `<limits.h>` 查。无符号整数溢出后按模 $2^n$ 回绕；有符号整数溢出不能这样推结果。

### 2.3 基本类型、常量与变量

基本类型先按下面这几类记：

- 整型：`char`、`short`、`int`、`long`、`long long`，以及对应的 `unsigned` 类型；
- 浮点型：`float`、`double`、`long double`；
- 空类型：`void`。

常量的常见写法：

```c
42          /* 十进制整数 */
052         /* 八进制整数，等于十进制 42；08 不是合法八进制常量 */
0x2A        /* 十六进制整数 */
42U         /* unsigned int */
42L         /* long */
3.14        /* double */
3.14f       /* float */
2.5e-3      /* 科学计数法 */
'A'         /* 字符常量 */
"A"         /* 字符串，占两个 char：'A' 和 '\0' */
```

转义字符包括 `\n`（换行）、`\t`（制表）、`\\`（反斜杠）、`\'`、`\"` 和 `\0`。字符在计算中按其字符编码值参与整型运算，如 `'7' - '0'` 得到整数 `7`。

变量先定义再使用。全局变量和静态变量没有手动给初值时会被置 0；普通局部变量不会，刚定义就拿来算通常会得到乱值。

```c
const double pi = 3.141592653589793;
unsigned long count = 0UL;
char grade = 'A';
```

`const` 表示不通过这个名字修改对象。它和宏常量不是一回事：`const` 变量有明确类型，也受作用域限制。

### 2.4 `sizeof` 与类型转换

`sizeof` 算一个类型或对象占多少字节，写成 `sizeof(类型)` 或 `sizeof 表达式`。有个容易出现在读程序题里的细节：`sizeof(i++)` 只看 `i` 的类型，并不会真的执行 `i++`。

不同类型混在一个表达式中时，会先按类型等级自动转换；赋值时还要再转成左边变量的类型。最常考的是整数除法：

```c
double x = 5 / 2;          /* 先做整数除法，x 为 2.0 */
double y = 5.0 / 2;        /* y 为 2.5 */
int n = (int)3.8;          /* 强制转换，截去小数部分，n 为 3 */
```

强制类型转换只管这一次计算，原变量的类型并没有变。

## 3. 数据的输入与输出

C 语言把输入输出放在库函数里。键盘输入通常走 `stdin`，屏幕输出走 `stdout`；`stderr` 专门留给错误信息。

### 3.1 `printf`

```c
printf("格式控制字符串", 输出项1, 输出项2, ...);
```

常用格式说明如下：

| 类型 | 常用格式 | 说明 |
| --- | --- | --- |
| `int` | `%d`、`%i` | 有符号十进制 |
| `unsigned int` | `%u`、`%o`、`%x`、`%X` | 无符号十、八、十六进制 |
| `long` / `long long` | `%ld` / `%lld` | 长整型、超长整型 |
| `double` | `%f`、`%e`、`%g` | `printf` 中 `float` 会提升为 `double` |
| `char` | `%c` | 单个字符 |
| 字符串 | `%s` | 输出到 `\0` 为止 |
| 指针 | `%p` | 参数应转换为 `void *` |

再记一下场宽和精度：`%8.2f` 表示总宽度至少为 8，小数点后留 2 位；`%-8d` 左对齐；`%08d` 用 0 补齐。实际内容超过场宽时照常输出，不会为了凑宽度把数字截掉。

格式符和变量类型一定要对上。`printf("%d %d", i++, i++)` 这种写法也别用：两个实参谁先算没有固定顺序，没法可靠判断输出。

### 3.2 `scanf`

```c
int a;
double x;
char word[20];
int ok = scanf("%d%lf%19s", &a, &x, word);
```

- 普通变量要传地址，所以通常要写 `&`；字符数组名本身就能表示首地址，不再加 `&`；
- `float *` 用 `%f`，`double *` 用 `%lf`，不要与 `printf` 的规则混淆；
- `%s` 应限制最大宽度，给结尾的 `\0` 留出一个位置；
- `%c` 不跳过空白，常写成 `" %c"`，前面的空格会吃掉残留空白；
- `%*d` 表示读入一个整数但不保存；
- 返回值是成功赋值的项目数，输入结束且没有完成任何转换时返回 `EOF`。

```c
while (scanf("%d", &a) == 1) {
    /* 每次只处理一次有效输入 */
}
```

格式串里的普通字符也要匹配。比如 `scanf("%d,%d", &a, &b)` 规定了两个数中间必须输入逗号，这一点很容易看漏。

### 3.3 字符与字符串输入输出

`getchar()` 每次读一个字符，但返回类型是 `int`，因为除了正常字符还要表示 `EOF`。所以要判断文件结束时，接收变量也用 `int`：

```c
int ch;
while ((ch = getchar()) != EOF) {
    putchar(ch);
}
```

`puts` 输出字符串并自动换行。读取一整行应使用 `fgets`：

```c
char line[100];
if (fgets(line, sizeof line, stdin) != NULL) {
    /* 成功读入，换行符可能仍在 line 中 */
}
```

课件特别提醒不要把 `scanf` 和 `gets` 混着用，前一个函数留在输入缓冲区里的换行会被后一个函数直接读走。`gets` 本身也没有长度限制，现在已经不再使用；课内只读一个不含空格的字符串时，用带宽度的 `%s` 即可。

课件还讲了 `_getch`、`_getche` 和 `_ungetch`。它们来自 `<conio.h>`，在 Visual C 一类环境里能用，但不是标准库函数。标准 C 中把字符退回输入流用的是 `ungetc`。

## 4. C 表达式与宏定义

### 4.1 赋值、算术、关系与逻辑运算

赋值表达式本身也有值，值就是最后赋进去的内容；而且赋值从右向左结合，所以 `a = b = 0` 会先把 0 给 `b`，再给 `a`。

`+=`、`-=`、`*=`、`/=`、`%=` 是复合赋值。`a += b + 3` 等价于 `a = a + (b + 3)`，右边的括号不要忘。

整数的 `/` 舍去小数部分，C99 起结果向 0 截断；余数满足 `(a / b) * b + a % b == a`，余数与被除数同号。`%` 只能用于整数。

关系运算的结果只有 0 或 1。程序能编译但判断总是不对时，先看看是不是把 `==` 写成了 `=`：

```c
if (x = 0) { ... }   /* 给 x 赋 0，条件恒假 */
if (x == 0) { ... }  /* 判断 x 是否为 0 */
```

逻辑非、与、或分别为 `!`、`&&`、`||`。C 中 0 为假，非 0 为真。`&&` 和 `||` 采用短路求值：

```c
if (p != NULL && *p > 0) { ... }  /* p 为空时不会计算 *p */
```

另一个常见坑是 `0 < x < 10`。C 会先算 `0 < x`，得到 0 或 1，再拿这个结果和 10 比，所以这个条件几乎总为真。区间要拆开写成 `0 < x && x < 10`。

### 4.2 其他运算符

- 前置 `++i`：先增加，再产生新值；后置 `i++`：先产生旧值，再增加；
- 条件运算：`条件 ? 表达式1 : 表达式2`，只计算其中一个分支；
- 逗号运算：从左到右计算，整个表达式的值为最后一项的值；
- 取地址与间接访问：`&x`、`*p`；
- 成员访问：`.` 与 `->`；
- 数组下标和函数调用：`[]`、`()`。

优先级只负责“怎么加括号”，不负责“先算左边还是右边”。这一点和数学式不太一样。读程序时如果一眼看不清，先自己补括号。

### 4.3 标准数学函数

`<math.h>` 中常用函数包括 `sqrt`、`pow`、`fabs`、`exp`、`log`、`sin`、`cos`。参数和返回值通常为 `double`。

```c
#include <math.h>
double distance = sqrt(x * x + y * y);
```

在部分 Unix 编译环境中，链接时还要加 `-lm`。

### 4.4 宏定义

```c
#define PI 3.141592653589793
#define SQUARE(x) ((x) * (x))
#define TO_STRING(x) #x
```

宏就是预处理阶段的文本替换，没有函数那样的类型检查。带参数宏的坑主要有两个：一是括号，二是参数可能被展开多次。上面的 `SQUARE(i++)` 会把 `i++` 展开两遍，绝不是普通函数调用的效果。

宏替换体里的 `#` 把实参变成字符串，`##` 把两个记号拼在一起；多行宏用反斜杠续行。普通常量用 `const` 往往更清楚，简单计算也尽量写函数，宏留给确实需要文本替换的地方。

## 5. 选择结构

### 5.1 语句、复合语句和作用域

表达式后面加分号就是一条语句；单独一个分号则是空语句。花括号把若干声明和语句包成一个复合语句，同时也划出一层新的作用域。

```c
if (condition);     /* 这个分号是空语句 */
{
    work();         /* 无论条件真假都会执行 */
}
```

### 5.2 `if` 与 `if ... else`

```c
if (score >= 60) {
    puts("pass");
} else {
    puts("fail");
}
```

没有花括号时，`else` 会找离它最近、还没配对的 `if`。缩进不参与语法判断，不能只看代码排得像不像一组。

多分支一般串成 `if - else if - else`。判断成绩等级时要从高分往低分写；如果第一句就是 `score >= 60`，后面的 80、90 分分支永远走不到。

### 5.3 条件运算符

条件运算符适合二选一地取一个值：

```c
max = a > b ? a : b;
```

分支里要做很多事时，直接写 `if`，不必硬塞成一行。

### 5.4 `switch`

```c
switch (op) {
case '+':
    result = a + b;
    break;
case '-':
    result = a - b;
    break;
default:
    puts("unknown operator");
    break;
}
```

`switch` 只能按整数或枚举值分支，`case` 后面也必须是互不重复的整型常量。看到 `case` 时顺手检查 `break`：没有它，程序会从匹配处一直往下跑。确实想让两个分支共用代码时可以故意不写，但最好留一句注释。

## 6. 编译预处理

预处理发生在正式编译之前。命令都以 `#` 开头，不是 C 语句，末尾也不加分号。

### 6.1 文件包含

```c
#include <stdio.h>     /* 通常从系统头文件目录查找 */
#include "my_math.h"   /* 通常先从当前工程查找 */
```

头文件里通常放类型定义、宏、常量和函数声明。为了防止同一个头文件被反复展开，要加包含保护：

```c
#ifndef MY_MATH_H
#define MY_MATH_H

double mean(const double a[], int n);

#endif
```

`#include` 做的是原样插入文件内容。工程里包含头文件 `.h`，不要为了省事去 `#include "file.c"`，否则源文件中的定义很容易重复。

### 6.2 条件编译

```c
#ifdef DEBUG
    fprintf(stderr, "x = %d\n", x);
#endif

#if VERSION >= 2
    /* 新版本代码 */
#else
    /* 兼容代码 */
#endif
```

`defined(NAME)` 可以在 `#if` 中检查宏有没有定义。条件编译是在编译前决定某段代码留不留下；普通 `if` 则是在程序运行时选择，两者不要混在一起。

### 6.3 `#pragma` 与 `#line`

`#pragma` 用来给编译器传一些额外指令，各家编译器不完全一样。课上重点是 `#pragma pack(n)`：它会改结构体成员的对齐方式，用完要恢复，不然后面定义的结构体也会受影响。

`#line 行号 "文件名"` 修改编译器此后报告的逻辑行号和文件名，常用于代码生成工具，普通程序很少直接使用。

## 7. 循环结构

### 7.1 `while`、`do ... while` 与 `for`

三种循环先分清判断时机：`while` 先判断，第一次条件就不成立时一遍也不执行；`do ... while` 先做一遍再判断，所以至少执行一次；`for` 只是把初始化、条件和更新集中写在了一行。

```c
while (condition) {
    /* 循环体 */
}

do {
    /* 循环体 */
} while (condition);

for (初始化; 条件; 更新) {
    /* 循环体 */
}
```

循环写错往往不是语法问题，而是差一轮。拿不准 `<` 还是 `<=` 时，别凭感觉，直接把第一次和最后一次循环的变量值写在纸上。

`for` 的三个表达式均可省略。省略条件相当于真，但循环仍要通过 `break` 等方式退出。

中间的表达式是“循环是否继续”的条件，不是“满足后只执行一次”的 `if`。另外，`while (条件);` 后面那个分号代表空循环体；条件一直为真时，后面的花括号永远也执行不到。

### 7.2 嵌套、`break` 与 `continue`

循环嵌套时，每执行一轮外层循环，内层循环都要从头跑一遍。因此内层循环变量要重新初始化；忘了这一点，第二轮外循环里内层循环可能一次也不进。

- `break` 只跳出它所在的最内层循环或 `switch`；
- `continue` 跳过本轮余下语句，进入下一轮；
- 在 `for` 中，`continue` 后先执行更新表达式；在 `while` 中则直接判断条件，注意不要漏掉必要的状态更新。

`break` 只能跳一层。要一次离开多层循环，可以设标志，也可以把这段搜索单独写成函数，找到答案就直接 `return`。

### 7.3 输入循环

连续读数据时，直接拿输入函数的返回值控制循环最省心：

```c
int x, sum = 0;
while (scanf("%d", &x) == 1 && x > 0) {
    sum += x;
}
```

`while (!feof(stdin))` 看起来合理，实际会慢一拍：只有读取已经失败，文件结束标志才会出现，上一组数据可能因此被处理两遍。

### 7.4 常用算法思路

候选范围不大时可以直接**列举**，把所有可能都试一遍；如果候选需要边生成边调整，就是**试探法**。课件里的密码问题、四叶玫瑰数都属于这一类。这些题的循环通常不难，难的是有没有漏掉判定条件。

整数拆位经常成对出现：`n % 10` 取出个位，`n /= 10` 再删掉个位。例如判断回文数，就是一边取位一边拼出逆序数。

数值计算题则是另一套循环：级数求和要同时更新通项和总和；二分求根每次保留仍然夹着根的半个区间；梯形积分把区间切成小段后逐段累加。这里的循环次数或误差阈值都要写清楚，否则很容易多算一项或一直不结束。

## 8. 模块设计（函数）

### 8.1 函数的声明、定义与调用

一个函数最好只做一件说得清的事。比如“读入数组”“找最大值”“输出结果”可以分开写，这样某一步出错时也知道该查哪一段。

```c
double max(double a, double b);     /* 声明，也叫函数原型 */

double max(double a, double b)      /* 定义 */
{
    return a > b ? a : b;
}
```

编译器看到函数调用之前，至少要先见过函数声明。`void` 函数不返回结果；其他函数走到正常出口时要有对应的 `return`。执行 `return` 后，当前函数剩下的语句不会再跑。

### 8.2 参数传递

C 只有**值传递**。调用函数时，实参的值被复制给形参；函数里改的是副本，外面的变量不会跟着变。下面第一个 `swap` 看着像交换，实际什么也没交换：

```c
void swap_wrong(int a, int b)
{
    int t = a;
    a = b;
    b = t;               /* 只交换了副本 */
}

void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}
```

平时说的“传地址”，本质上仍然是值传递，只不过这次复制的值恰好是地址。函数通过地址找到原变量，才真的改到外面。

### 8.3 作用域、存储期与链接

- 块内定义的名字只能在这一层花括号内使用；函数外定义的名字具有文件作用域；
- 普通局部变量每次进入函数都会重新产生，离开后失效；
- `static` 局部变量只初始化一次，下次调用函数时还保留上次的值；
- 全局变量在整个运行期间都存在，但用得太多会让函数之间互相牵连；
- 文件作用域的 `static` 函数或变量只在本源文件可见；
- `extern` 用来声明“这个外部名字定义在别处”。

课件把作用域归纳为全局、文件、函数和复合语句几层。做读程序题时，先看变量定义在哪一层花括号里，再判断当前语句究竟用的是哪一个同名变量。

内外层出现同名变量时，里层会把外层遮住。还要特别留意：普通局部变量在函数返回时就没了，不能把它的地址返回出去。

### 8.4 递归

递归先别急着在脑中一层层展开，先找两件事：**什么时候停**，以及**问题规模怎样变小**。例如阶乘在 `n <= 1` 时直接返回，否则把问题交给 `factorial(n - 1)`：

```c
long long factorial(int n)
{
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

每层递归都有自己的一套形参和局部变量。读递归程序时，可以从最小输入开始画调用过程，再逐层把返回值带回来。层数太深会耗尽调用栈。

Hanoi 塔的分法很典型：先把 $n-1$ 个盘移到辅助柱，移动最大的盘，再把那 $n-1$ 个盘移到目标柱。三步里第一步和第三步与原问题同形，只是规模少了 1。

## 9. 数组与字符串

### 9.1 一维数组

数组把一批同类型元素连续放在内存中，下标从 0 开始：

```c
int a[5] = {1, 2, 3};        /* 其余元素初始化为 0 */
int b[] = {1, 2, 3, 4};      /* 编译器推断长度为 4 */
int n = sizeof b / sizeof b[0];
```

按本课程使用的编译环境，定义数组时长度要写整型常量表达式，可以用符号常量，不能临时输入一个变量再写 `int a[n]`。

长度为 `n` 的数组，合法下标只有 `0` 到 `n - 1`。C 不替我们查越界，写到 `a[n]` 已经出了数组。数组定义好后也不能整体赋值，比较内容时要逐个元素比。

### 9.2 二维数组

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

二维数组按行存放：第一行放完，紧接着才是第二行。`matrix[i][j]` 等价于 `*(*(matrix + i) + j)`。作为函数参数时第一维可以不写，但列数不能省，因为编译器要靠列数算“跨过一行”究竟跨多少元素：

```c
void print_matrix(int a[][3], int rows);
/* 等价参数形式：void print_matrix(int (*a)[3], int rows); */
```

### 9.3 数组作为函数参数

数组传进函数后只剩首元素地址，长度信息不会跟着过去，所以数组长度要另外传。形参虽然写成 `int a[]`，到函数里实际按 `int *a` 处理；此时 `sizeof a` 得到的是指针大小，不是原数组大小。

若函数只读取数组，可写：

```c
double average(const double a[], size_t n);
```

只读数组参数加上 `const`，一眼就能看出这个函数不会改数组内容。

### 9.4 字符数组与字符串

C 字符串没有单独的字符串类型，就是一串以 `\0` 结尾的字符。有没有这个结尾，决定了它能不能安全地交给 `strlen`、`printf("%s")` 等字符串函数：

```c
char s1[] = "hello";         /* 可修改数组，大小为 6 */
const char *s2 = "hello";    /* 指向字符串字面量，不应修改 */
char s3[5] = {'h', 'e', 'l', 'l', 'o'}; /* 没有 \0，不是 C 字符串 */
```

常用 `<string.h>` 函数：

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `strlen(s)` | 返回 `\0` 前的字符数 | 不含 `\0` |
| `strcpy(dst, src)` | 复制字符串 | 目标空间必须足够 |
| `strcat(dst, src)` | 追加字符串 | 目标空间必须足够 |
| `strcmp(a, b)` | 按字典序比较 | 返回负、0、正，不保证是 -1/0/1 |
| `strchr(s, c)` | 查找字符 | 返回指针或 `NULL` |
| `strstr(s, sub)` | 查找子串 | 返回首次出现位置或 `NULL` |

`scanf("%s", s)` 一遇到空格就停，只适合读一个单词。要读整行用 `fgets`。旧代码里的 `gets` 没法限制长度，很容易越界，不要再用。

### 9.5 查找与排序

**顺序查找**就是从头比到尾，一般数组都能用。**二分查找**快得多，但前提是数组已经有序。每一轮看中点：相等就结束，目标更大就丢掉左半边，否则丢掉右半边。

```c
int binary_search(const int a[], int n, int key)
{
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == key) return mid;
        if (a[mid] < key) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

三种基础排序不要只背名字，要记住每一轮结束后“哪一部分已经有序”：

- 冒泡排序：相邻元素逆序就交换，一轮结束后最大值到了最右边；
- 选择排序：从未排序区找最小值，放到这一段最前面；
- 插入排序：左边始终有序，把当前元素向左插到合适位置。

三者平均时间复杂度都是 $O(n^2)$。读排序程序时先判断它维护的是哪一种“有序区”，内外层边界就容易看懂了。

课件里的其他数组题也可以按“下标代表什么”来整理：有序表插入、删除时要先给元素腾位置或补空位；用数组做超长整数时，每个元素存一位或一段数字；数值与下标映射时，先找出两者的换算关系。递归找最大值和递归排序，则是把数组前 $n$ 项的问题缩成前 $n-1$ 项。

## 10. 指针

### 10.1 基本概念

指针变量里存的是**地址**。`&` 取得变量地址，`*` 再按这个地址找到变量：

```c
int x = 3;
int *p = &x;
*p = 5;             /* x 变为 5 */
```

`int *p, q;` 中只有 `p` 是指针，`q` 仍然是普通 `int`。野指针不能解引用；暂时不指向对象时可设为 `NULL`，但 `NULL` 只是明确表示“没有指向”，照样不能写 `*p`。

`void *` 可以保存任意对象指针，转换回原类型后再解引用。指针类型不仅说明所指对象类型，也决定解引用方式和指针算术的步长。

### 10.2 指针运算与数组

若 `p` 指向数组元素，`p + 1` 就指向下一个元素。实际地址增加多少字节由 `p` 的类型决定：增量是 `sizeof *p`，并不是固定加 1 个字节。

在多数表达式中，数组名会转换为首元素指针：

```c
int a[10];
int *p = a;          /* 与 &a[0] 相同 */
a[i] == *(a + i);    /* 两种访问等价 */
```

不过 `sizeof a` 和 `&a` 是两个例外。`sizeof a` 算整个数组大小；`&a` 取得的是整个数组的地址，类型为 `int (*)[10]`，不是普通的 `int *`。

### 10.3 指针数组、数组指针和二级指针

声明应从变量名向外读：

```c
int *p[10];          /* p 是数组，有 10 个 int * 元素：指针数组 */
int (*q)[10];        /* q 是指针，指向含 10 个 int 的数组：数组指针 */
int **r;             /* r 指向 int *：二级指针 */
```

二维数组和 `int **` 不是一回事。二维数组的各行连续，传参时要用列数匹配的数组指针；`int **` 指向的是一个 `int *`，两者的内存结构并不一样。

### 10.4 动态内存

动态数组开在堆上，用完要自己释放。相关函数都在 `<stdlib.h>`：

- `malloc(bytes)`：申请指定字节数，内容未初始化；
- `calloc(count, size)`：申请元素数组，并把所有字节置 0；
- `realloc(ptr, new_size)`：调整内存块大小，地址可能改变；
- `free(ptr)`：释放动态内存，`free(NULL)` 合法。

```c
int *a = (int *)malloc(n * sizeof *a);
if (a == NULL) {
    /* 申请失败 */
}

/* 使用 a */

free(a);
a = NULL;
```

课件中的写法会把 `malloc` 返回的 `void *` 强制转换成目标指针类型。申请大小写成 `n * sizeof *a`，以后就算改了 `a` 的类型，这一行也不用跟着手改。

`realloc` 有个麻烦：扩容后地址可能改变，但失败时原来的内存又还在。因此先用临时指针接：

```c
int *tmp = (int *)realloc(a, new_n * sizeof *a);
if (tmp != NULL) {
    a = tmp;
}
```

动态内存的错来来回回就这几种：申请后忘记释放、同一块内存释放两次、释放后还在用、访问越界、拿不是动态申请的地址去 `free`。写代码时顺着每个 `malloc` 找一次对应的 `free`，比较不容易漏。

### 10.5 字符串指针

```c
char a[] = "abc";          /* 数组内容可修改 */
const char *p = "abc";     /* 指针可改指向，字面量不可修改 */
```

数组名不能改成指向别处，指针变量可以。两者都能访问字符串，但不是同一种东西。函数只读字符串时，参数写成 `const char *`。

### 10.6 函数指针和返回指针的函数

```c
double add(double x, double y) { return x + y; }

double (*operation)(double, double) = add;
double result = operation(2.0, 3.0);
```

函数指针最直观的用法是“把要调用的函数也当成参数传进去”。按条件选择不同运算、写回调函数时都会见到它。函数指针数组写作 `double (*ops[4])(double, double)`。

课件最后的变步长梯形求积就是函数指针的一个用法：积分程序只负责不断减小步长并比较两次结果，被积函数通过函数指针传进来，于是同一套积分程序可以计算不同函数。

返回指针的函数写作 `int *find(...)`。判断一个地址能不能返回，关键看函数结束后它指向的对象还在不在：局部自动变量已经没了，数组元素、动态内存、静态对象或调用者传入的对象仍可能有效。

### 10.7 `main` 的命令行参数

```c
int main(int argc, char *argv[])
{
    /* argc 是参数个数，argv[0] 通常是程序名 */
    return 0;
}
```

`argv` 是字符串指针数组，每个 `argv[k]` 指向一个参数字符串，`argv[argc]` 为 `NULL`。处理命令行参数时通常从 `argv[1]` 开始，因为 `argv[0]` 留给程序名。

## 11. 结构体、联合体、枚举与链表

### 11.1 结构体

数组要求所有元素同类型，而结构体正好用来把不同类型的数据捆在一起。例如一个日期同时有年、月、日：

```c
struct date {
    int year;
    int month;
    int day;
};

struct date today = {2026, 7, 14};
printf("%d-%02d-%02d\n", today.year, today.month, today.day);
```

`.` 跟在结构体对象后面，`->` 跟在结构体指针后面，`p->member` 就是 `(*p).member`。同类型结构体能整体赋值，也能作为函数参数和返回值；但 C 没有定义整个结构体的 `==`，比较时还是要看成员。

结构体按值传参会复制全部成员。结构体很大时通常传指针：只读就加 `const`，要修改就传普通结构体指针。

结构体成员本身还可以是结构体，也可以定义结构体数组。例如学生数组中的每个元素都是一份完整的学生记录。数组传给函数时仍按首元素地址处理，而单个结构体传参会把整个结构体复制一份，这两种情况不要混。

### 11.2 对齐与结构体大小

`sizeof(结构体)` 经常比各成员大小简单相加更大，因为编译器会在成员之间塞入填充字节来满足对齐。成员顺序一换，结构体总大小也可能跟着变。

`#pragma pack` 可以调整某些编译器的对齐规则。不过结构体直接写进二进制文件后，仍然可能受到字节序、类型宽度和浮点表示影响，换一台机器未必还能原样读。

### 11.3 单链表

单链表的结点分成数据域和指针域。结点在内存中可以东一块西一块，全靠 `next` 把逻辑顺序串起来：

```c
struct node {
    int data;
    struct node *next;
};
```

头指针为 `NULL` 表示空表。头插法建立链表：

```c
struct node *push_front(struct node *head, int value)
{
    struct node *p = malloc(sizeof *p);
    if (p == NULL) return head;
    p->data = value;
    p->next = head;
    return p;
}
```

遍历就是从头指针开始不断走 `next`，直到 `NULL`。链表题真正容易错的不是循环，而是改指针的顺序：旧的后继还没保存时不要先把链接断掉，`free(p)` 以后也不能再读 `p->next`。

```c
void clear(struct node **head)
{
    struct node *p = *head;
    while (p != NULL) {
        struct node *next = p->next;
        free(p);
        p = next;
    }
    *head = NULL;
}
```

要频繁按下标访问就偏向数组；已经拿到结点位置、又要经常插删时，链表更顺手。课件还用链表表示多项式：每个结点保存系数、指数和下一项指针，相加时按指数合并同类项。

### 11.4 联合体、枚举与 `typedef`

联合体的成员共用同一块内存，写入一个成员会覆盖原来的内容。它的大小至少要装得下最大的那个成员：

```c
union value {
    int i;
    double d;
    char text[20];
};
```

所以同一时刻通常只认最后写入的成员。实际使用时常再配一个枚举，专门记录“现在存的到底是哪一种数据”。

```c
enum color { RED, GREEN, BLUE };
typedef struct node Node;
```

枚举常量默认从 0 开始，也可以自己指定数值。`typedef` 只是给已有类型换个短一点的名字，并没有创造一种全新的类型。

## 12. 文件

### 12.1 文本文件、二进制文件与文件指针

文件操作的套路很固定：**打开，检查，读写，关闭**。哪一步失败都不能装作没看见。

文本文件保存的是字符，人能直接看懂，但数字读写时要做格式转换。二进制文件直接保存字节，通常更紧凑，不过会受类型大小、字节序和数据布局影响。

标准 I/O 用 `FILE *` 表示一个文件流。`fopen` 失败会返回 `NULL`，因此打开之后第一件事就是检查。

### 12.2 打开与关闭

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
    perror("data.txt");
    return 1;
}

/* 读写文件 */

if (fclose(fp) == EOF) {
    /* 关闭或刷新失败 */
}
```

打开模式主要看两件事：要读还是要写，原文件要保留还是清空。

| 模式 | 含义 |
| --- | --- |
| `r` | 只读，文件必须存在 |
| `w` | 只写；不存在则创建，存在则截断 |
| `a` | 追加；写入总在文件末尾 |
| `r+` | 读写，文件必须存在 |
| `w+` | 读写，创建或截断 |
| `a+` | 读和追加 |

后面加 `b` 就是二进制模式，如 `rb`、`wb`。在 Windows 中它会影响换行转换；Unix 下通常没有区别。

`w+` 和 `w+b` 都是“写、读”方式，区别在文本还是二进制；共同点是文件一打开，原内容就先被清空。需要保留旧数据时不能误用这两个模式。

### 12.3 文本读写

文本读写和键盘输入输出很像，只是多了一个文件指针：`fprintf`、`fscanf` 负责格式化数据，`fputc`、`fgetc` 每次处理一个字符，`fputs`、`fgets` 处理字符串或一整行。

```c
int id;
double score;
while (fscanf(fp, "%d%lf", &id, &score) == 2) {
    printf("%d %.1f\n", id, score);
}
```

上面循环里的 `== 2` 不能省，它表示这一轮确实读到了学号和成绩两个数据。循环结束后，再用 `feof(fp)` 判断是不是正常读到文件末尾，用 `ferror(fp)` 看有没有 I/O 错误；`clearerr(fp)` 可以清掉这两个状态。

格式化写文本时，数据之间要自己留空格、逗号或换行。连续写成 `fprintf(fp, "%d%lf", a, x)`，两个数可能直接粘在一起，之后就不一定能按原来的格式读回来。

### 12.4 二进制读写

二进制文件不做字符串转换，直接按“每个元素多大、一共有几个元素”读写：

```c
size_t written = fwrite(a, sizeof a[0], n, fp);
size_t read_n = fread(a, sizeof a[0], n, fp);
```

因此 `fread`、`fwrite` 的返回值也是成功处理的**元素个数**，不是字节数。比如要求读 10 个 `int`，返回 7 就表示只读到 7 个完整元素。

### 12.5 文件定位与缓冲

`rewind(fp)` 让文件位置回到开头。要从任意位置移动就用 `fseek`，起点可以选 `SEEK_SET`、`SEEK_CUR` 或 `SEEK_END`；`ftell` 则用来查看当前位置。这几个函数放在一起记，比单独背函数名好记。

文件刚写完时，位置通常已经在末尾。如果接下来还要从头读，先 `rewind` 或 `fseek`，否则第一次读取就可能失败。

`fflush(fp)` 做的是另一件事：把输出缓冲区真正写出去。课件里提到的 `fflush(stdin)` 在部分编译器上被当作清空输入，但这不是标准 C 的通用写法。

## 13. 位运算

位运算就是直接对整数的二进制位动手。写掩码、做移位时尽量用无符号整数，规则更直观。

### 13.1 六种位运算

| 运算符 | 作用 | 常见用途 |
| --- | --- | --- |
| `&` | 按位与 | 保留选定位、清零其他位 |
| `|` | 按位或 | 把选定位设为 1 |
| `^` | 按位异或 | 翻转选定位、比较位差异 |
| `~` | 按位取反 | 所有位翻转 |
| `<<` | 左移 | 向高位移动 |
| `>>` | 右移 | 向低位移动 |

```c
unsigned flags = 0;
const unsigned READ = 1u << 0;
const unsigned WRITE = 1u << 1;

flags |= READ;             /* 置位 */
flags &= ~READ;            /* 清零 */
flags ^= WRITE;            /* 翻转 */
if ((flags & WRITE) != 0) {
    /* 测试某一位 */
}
```

对无符号数，在没有移出有效位的前提下，左移 $k$ 位相当于乘 $2^k$，右移相当于除 $2^k$。移位数不能是负数，也不能大于等于类型本身的位数。负的有符号数移位规则不够统一，做位操作时避开它最省事。

位运算的优先级很容易记错，`(x & mask) == 0` 里的括号别省。

检查某一位时要用掩码。例如判断第 3 位是否为 1，可以写 `if (x & 0x08)`；不能写成 `x == 0x08`，因为 `x` 的其他位也可能同时为 1。

### 13.2 位段

位段是在结构体成员后面写明要占几位：

```c
struct status {
    unsigned ready : 1;
    unsigned error : 1;
    unsigned mode  : 3;
};
```

位段能紧凑地保存多个标志。不过成员究竟怎样排列、是否跨存储单元都可能随编译器改变，遇到必须精确规定每一位的文件或协议时，用无符号整数配合掩码更稳妥。
